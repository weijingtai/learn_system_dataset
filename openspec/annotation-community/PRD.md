# 笔记、原句注解与讨论系统 PRD

版本：1.0；日期：2026-09-10。
状态：`CONFIRMED_REQUIREMENTS`。用户已确认功能方向及默认规则，并要求产出开发文档；这不表示实现、外部协议或生产验收已完成。

阅读顺序：[PRD](PRD.md) → [Design](DESIGN.md) → [Plans](PLANS.md) → [Tasks](TASKS.md)。本文件是社区线产品需求基线，不修改知识编译黑箱的单机边界。旧讨论稿只作来源；本期范围冲突以本文件和用户后续决定为准。

## 1. 产品目标

用户能够阅读原书、选择原句写注解，也能独立编写 Markdown 笔记。内容默认私密，可端到端同步并选择加密云备份；用户明确发布后，其他人可阅读、评论、回复和互动。原书阅读与知识 Tooltip 查询同一组关联内容和讨论。

成功不是界面按钮齐全，而是保存可恢复、发布权限有效、历史可追溯、通知可送达、原句可准确定位。用户内容不直接改变官方知识、证据或发布资格。

## 2. 用户与身份

- 本人：管理私人内容、修订历史、备份、发布状态和回收站。
- 其他账号：阅读允许公开的内容、互动、举报或通过已有 IM 联系作者。
- 宿主审核角色：沿用既有权限隐藏/恢复违规公共内容，不获取私人备份解密权。
- 复用宿主账号与登录系统；公开身份为可追溯账号昵称，不支持匿名发布，不要求将私人内容公开。
- 已授权账号可离线编辑；登录过期、账号切换、设备吊销不得导致跨账号读取或发布。

## 3. 本期需求与可观察验收

| ID | 需求 | 验收结果 |
|---|---|---|
| R-01 | 独立 Markdown 笔记 | 不选择书籍也能创建、编辑、预览、保存和发布；渲染使用 flutter_markdown_plus |
| R-02 | 本地优先保存 | 停止输入 2 秒后自动保存；失焦/返回时立即尝试保存；持久成功才显示本地已保存，失败保留编辑内容 |
| R-03 | 本期撤销/重做 | 支持规定快捷键与触控按钮，覆盖输入、删除、粘贴、格式插入和图片引用插入；见 §4 |
| R-04 | 不可变修改历史 | 每次有效保存留修订；相同内容不重复建版本；作者可看差异并恢复，恢复生成新修订 |
| R-05 | 私密与显式发布 | 默认私密；发布选定修订；公开后编辑仍为私人修改，点击更新发布才改变公共正文 |
| R-06 | 原句注解 | 对合法原文选区创建注解，保存所见精确版本；重复句不误绑，无知识标签正文也应可注解 |
| R-07 | 两入口互通 | 原书和相关 Tooltip 返回相同内容/讨论身份；整本书关联不自动扩散至每个知识点 |
| R-08 | 两级评论/回复 | 一级评论默认最新，可切最早；楼内时间正序；回复任意楼内对象仍为第二级 |
| R-09 | 点赞/点踩 | 内容、注解、评论/回复支持互斥赞踩及取消；重试不重复计数 |
| R-10 | 收藏/分享/关系联动 | 支持收藏、分享、稳定账号 @、资料、关注、已有私信、举报、拉黑；不重复创建账号或 IM 系统 |
| R-11 | 通知 | 评论、回复、@ 进入通知程序；重复收件人合并，不通知自己；通知点击重新鉴权并定位 |
| R-12 | 私人多设备同步 | 同账号已授权设备端到端同步笔记/修订/附件；冲突保留双方版本，用户选择或手动合并 |
| R-13 | 加密云备份 | 首次明确选择；启用后自动备份，关闭只停止后续上传，删除云备份是独立操作；不以中转成功代替备份 |
| R-14 | 收回/删除/恢复 | 收回关闭公开访问；删除进入 30 天回收站，恢复保持私密；彻底删除与同步/备份清理有明确状态 |
| R-15 | Markdown 图片 | 本期支持图片；私人图片加密，发布只公开选定版本所需资源；图片访问受当前可见性限制 |
| R-16 | 离线公共操作 | 可保留待提交发布/收回/评论，服务端确认前不显示已成功；公共内容不承诺完整离线阅读 |
| R-17 | 原书资产接入 | 按共同协议消费扫描/PDF/EPUB/TXT，服务器不重复 OCR、解码、清洗、拆章或重编号；按格式/能力验收 |
| R-18 | 前后端契约与复用 | Flutter/Drift、Python Functions/Firestore、REST/JSON、OpenAPI 3.1/Swagger；优先复用现有模块 |
| R-19 | 真实 Tooltip 原型 | 有来源、内容、评论回复、互动、资料/私信和通知回跳；使用真实后端，不负责嵌入具体排盘盘面 |
| R-20 | 隐私与审核一致性 | 私有/收回/隐藏内容不得经历史、附件、分享、关联索引或通知正文绕过权限；公开数据不回写官方知识 |

## 4. 本期撤销、重做与键盘边界

| 平台 | 撤销 | 重做 |
|---|---|---|
| Windows/Linux | Ctrl+Z | Ctrl+Shift+Z 或 Ctrl+Y |
| macOS | ⌘Z | ⌘⇧Z |
| 手机/平板 | 撤销按钮 | 重做按钮 |

本期提供 Undo/Redo 编辑动作及上述平台按键映射。按钮在无可操作历史时禁用。

- 连续输入合理归组；粘贴、格式、图片插入各自构成完整操作。
- 中文输入法组合过程作为整体，不逐个拼音键拆分历史，不拦截输入法正在使用的按键。
- 自动保存不清空撤销栈；撤销后新增编辑清空原重做分支。
- 撤销只改变当前编辑内容；保存后生成新的持久修订，不删除过去的审计历史。
- 撤销不执行“撤回发布”、删除云备份等远端业务命令。撤销图片引用不立即删除仍被历史版本引用的图片。
- 本期不跨重启持久化撤销栈；重新打开使用持久历史恢复旧版本。
- **完整键盘操作设计当前缺失并明确后置**：不在本期设计或承诺其他自定义快捷键、快捷键配置及跨页面键盘导航方案。保留平台普通输入行为，不禁用现有系统能力。

## 5. 已定案的默认规则

| 事项 | 本期规则 |
|---|---|
| 自动保存 | 2 秒去抖；失焦/返回尝试立即落盘；有效内容变化才新增修订 |
| 历史展示 | 编辑会话归组，支持逐修订查看差异；不会覆盖持久版本 |
| 冲突 | 保留双方版本；选择/手动合并产生新修订，不做实时多人协同 |
| 云备份 | 首次明确选择，启用后自动；关闭/删除分开 |
| 回收站 | 30 天；恢复仍私密；到期及彻底删除进入可重试清理流程 |
| Markdown | 源码编辑、预览、工具栏、图片、撤销重做、历史；通用附件后置 |
| 排序 | 一级默认最新，可最早；楼内时间正序；无热度推荐算法 |
| 通知 | 评论/回复/@ 必须进入通知管线，按既有拉黑/偏好处理投递；赞进入站内通知，系统提醒遵守偏好；踩/收藏/分享默认不通知 |
| 公开离线 | 不承诺完整公共离线阅读；重连核验可见性；服务端确认后才报告公共写入成功 |
| 审核 | 复用举报、拉黑与人工处置；不新增自动审核服务 |

已公开过的内容无法从他人截图或合法离线副本中远程抹除。收回承诺为阻止新的服务端访问和在线视图失效；不能一边发永久公开图片 URL，一边承诺立即撤权。

## 6. UI 与用户旅程

1. 我的笔记列表 → 新建 → 编辑/预览 → 本地保存 → 查看历史；显示本地、设备同步、云备份三个状态。
2. 原书阅读 → 选文字 → 新建私密注解或查看公开注解 → 打开讨论 → 回复/@ → 接收方从通知返回同一楼内回复。
3. 私人笔记 → 发布预览（明确修订与图片）→ 发布 → 编辑私人草稿 → 更新发布或收回。
4. 内容详情 → 资料 → 沿用宿主关注/私信流程；举报/拉黑影响后续交互与通知。
5. 我的笔记 → 移入回收站 → 恢复或彻底删除；待撤公开、待清理、清理失败可区分。

原书、注解、笔记交付正式 Flutter UI；Tooltip 交付真实链路原型及 UI 调用协议，不交付占卜模块里的最终嵌入 Widget。加载、空态、离线、失权、保存失败、冲突和重试均纳入界面验收。
