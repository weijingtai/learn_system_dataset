## 0. 根本需求、最高哲学与禁区【高于一切】

### 0.1 根本需求：把师傅的眼睛借给新手

专家与新手看同一张盘，区别首先不是知识量，是**注意力结构**。老手扫盘有固定次序：先看气（月令旺衰），再看作用（生克合冲），再看形（格局），再看职（用神），最后落断。新手的眼睛在盘上均匀漫游——什么都看见，什么都没看见。

**Marks 系统是专家注意力结构的编译产物。** 每个物种对应"师傅此刻会看哪里、看什么"：徽标是扫气的那一眼，关系线是察作用的那一眼，印章是识形的那一眼，角标是认职的那一眼。

同时它是象法记忆系统的显示层基础设施：暴露策略决定用户看见什么、多少次；本系统决定每次看见的形式是否一致到足以沉淀。一句话定位：**让旺衰生克像交通标志一样被习得**——靠形状语法的绝对一致性，不靠教。

### 0.2 最高哲学

**借你师傅的眼，不替你下师傅的断。**

专家看盘五层：气 → 作用 → 形 → 职 → **断**。Marks 覆盖前四层，永远不进第五层。裁决层属于用户（学习者练的就是这一步）与 AI 解释链路（带溯源、条件、流派）。

每个标记的快速测试：它在告诉用户"这里值得看、这是什么"（注意＋识别，放行），还是"你这件事的结果"（裁决，禁区）？

### 0.3 吉凶划界：断格不断事

吉凶标记不是禁区，个人化的吉凶裁决才是。吉凶在典籍中本就是分类属性（开休生为三吉门、白虎猖狂为凶格），抹掉它盘就没法看，行家会立刻识破产品不懂行。

**允许**：元素级、典籍级吉凶属性，附四个条件：

1. 作用于盘面元素，而非用户之事；
2. **吉凶三件套**同时可及：典籍定义属性＋格局制化条件＋流派差异说明。条件必须双层——① 格局的典籍吉凶定义；② 格局是否得用、得制、得运（"白虎猖狂"不仅"得制反吉"，还有"得时得用不凶、失运叠加更凶"）；
3. 出处可溯源；
4. **静态盘标注**：明示所展示的是命盘／课盘的静态格局属性，绝不关联用户具体占问。新手极易自行联想，须以固定标注对抗（文案与出现频率见 §11-4，防免责疲劳）。

**三条禁区**：

- **聚合裁决**：把元素级吉凶加总成"本盘大凶／此事不吉"的整体判决——从知识滑向宣判、从文化内容滑向算命断语的那一步；
- **氛围渲染**：页面色调、背景、动效随用户盘面吉凶变化。潜意识通道只运送概念，不运送恐惧；
- **无条件裸奔**：吉凶标记出现而条件不可及——**在视觉与听觉（读屏）两个通道同时适用**（见 §1-N7）。

一句话：**吉凶是格局的属性，是知识；你这件事怎么样，是判断——标记只交付前者。**（"断象不断事"的姐妹原则）

### 0.4 五问审计（每个标记、每个物种的通用验收）

1. 对应专家注意的哪一层（气／作用／形／职）？
2. 形状语法归哪族（状态／关系／角色／结构／元数据／装饰／聚合）？
3. 携带的吉凶是典籍属性还是个人裁决？（卡在此问即需改造）
4. Concept ID 与溯源在哪？
5. 出现在哪些场景、哪个密度层级？

审计范围包括：视觉文案、accessibility label、动效、色彩提级依据——任何向用户传递语义的通道。

## 1. 需求分析（八项）

**N1 认知：无意识习得语义结构。** 新手需在不学习状态下分清四类概念：旺衰是状态、生克是关系、格局是结构、用神是角色——四类混成一锅"黑话"是学习第一道墙。科学基础：前注意加工（形状、颜色、方向在约 200ms 内被无意识处理）——"潜意识接收"的工程实现。另含两个底层认知偏差的主动矫正：**旺衰≠吉凶、格局≠成败**——视觉中性化只解决旺衰层，格局与神煞需吉凶三件套＋词条矫正话术共同对抗。

**N2 区分：类别一眼可辨。** 类别间视觉距离必须大于类别内视觉距离。全部做成彩色胶囊＝没有系统。

**N3 信任：知识与元知识隔离。** 流派、审核状态、机器释义标识是"关于知识的状态"，与术数语义混排同时伤害学习（语法污染）与信任（分不清哪些是古籍说的）。

**N4 安全：不传达吉凶判决。** "旺=绿=好、死=红=坏"是最危险的默认设计——教错知识（忌神旺是坏事）且构成隐性宣判。特殊格局（从旺、从弱、专旺）下取用相反：能量标记保留形态，词条强制标注"格局反转，旺衰取用相反"。

**N5 一致：跨技法、跨场景同形。** 旺相休囚死在奇门／八字／六爻同形；技法特有概念走扩展但继承同一形状语法。Marks 分类学＝知识对象模型的显示层投影。

**N6 国际化【v0.4 升为一等需求】。** 港台是既定海外优先市场：繁简体（繁简转换属"派生层不冒充原文"原则的适用对象）；生僻字缺字风险（孛、罡、煞类异体）；英文 tag 宽度破坏中文单字尺寸系统；五行色跨文化语义（黑=水的西方负面联想）。Registry 须有 locale 维度，尺寸系统按最长 locale 设计。

**N7 无障碍：视觉＋听觉双通道【v0.4 升为一等需求】。** 约 8% 男性色觉异常→颜色永不单独承载语义；动态字号（用户群含中老年）；**读屏通道**：accessibility label 同样过五问审计、走溯源管线——裸的"凶格"label 是禁区三在听觉通道的重演；ambient 动效尊重系统"减少动态效果"。

**N8 性能。** 目标用户含下沉市场安卓机。单屏 marks 渲染上限、ambient 动效同屏上限、低端机帧预算与静态降级（见 §5.3）。

## 2. 交互模型【本规范的骨架】

### 2.1 可达 ≠ 可点

Fitts 定律下可点击目标最小约 44pt，而 marks 的使命是小而不抢——两者物理冲突。模型：

- **盘面 marks 是纯视觉态**，不直接响应点击；
- 点击**元素**（宫位／星／爻／干支）弹出**元素详情卡**；
- **内联变体**（正文流中的着色文字＋轻下划线）保持直接可点；
- 原则表述修正："每个标记可溯源、可达"，而非"可点"。

### 2.2 元素详情卡（Tap 层枢纽，新组件）

承载被点元素全部 marks 的展开层，自上而下：

```text
┌─ 元素详情卡 ──────────────────────┐
│ 元素本体（名称＋五行身份色）         │
│ 状态区：能量条足尺寸＋当前梯度文字    │
│ 关系区：与其他元素的生克合冲（可展开） │
│ 角色区：本次占问中的职务（动态）      │
│ 结构区：所参与格局＋吉凶三件套        │
│ ──────── 元数据隔离区 ────────     │
│ 流派差异｜审核状态｜溯源入口          │
└──────────────────────────────────┘
```

- 吉凶三件套、流派分歧、静态盘标注实际居住于此；
- 弹出位置尊重单手拇指区；与盘面缩放／拖动手势明确仲裁（单击=详情卡，双指=缩放，长按=预留）。

### 2.3 文盘联动【P0 级，Marks 从标注系统升格为教学系统的那一步】

"读到的"与"看到的"必须连接——这是取象能力的实际形成方式：

- 正文 → 盘：点内联 tag（如"白虎猖狂"）→ 盘面对应宫位／元素高亮聚焦；
- 盘 → 正文：**经详情卡中转**（点元素 → 详情卡 → 点条目 → 正文相关段落滚动定位），与 §2.1"盘面 marks 不可点"保持一致，marks 本身永不直接响应点击；
- 高亮是**注意引导**（聚焦动效），永不携带吉凶色彩（禁区二）。

**联动的内容源按阶段收敛（D-021 修订，2026-07-11 用户裁决取代 D-004）**：

- 阶段零：人工证据卡 ↔ 静态示例盘；
- 阶段一：确定性计算事实（ComputedFact）↔ 原文／证据卡，**以及 AI 解盘与多轮对话**（D-021）——AI 回答中的格局、神煞、局等关键概念以内联 mark 高亮并联动盘面与词条；
- **高亮即验证门**：只有成功绑定已编译 Concept ID 的术语才高亮可点；AI 生成而无法绑定的术语渲染为普通文本——高亮本身成为幻觉的可视化过滤器，用户可学会"只信亮的"；
- AI 对话全程受既有约束架构管辖：EvidenceBundle 证据绑定、断象不断事、混派与引用检查、高风险场景拒绝（16A）、大陆合规 profile 描述式表述、AI 内容标识；多轮对话每轮重新校验，防长对话漂移；
- 付费可能性仅在此保留占位（订阅／次数均可），暂不展开分析。

跨组件 focus 联动协议进 registry 事件规范（§6.2），AI 对话、词条、证据卡、学习练习场景复用。

## 3. 视觉语法体系

### 3.1 双通道分离：形定类别，色定取值

| 族 | 语义性质 | 注意层 | 形状语法 |
|---|---|---|---|
| 状态 State | 单实体序数属性 | 气 | 灰度能量条＋五行色角标 |
| 关系 Relation | 二元有向作用 | 作用 | 连接线：箭头定指向、虚实定强弱、线色为双方身份色 |
| 角色 Role | 占问中的临时指派 | 职 | 角标／描边，附着于载体，**随占问动态刷新，禁止静态固化** |
| 结构 Pattern | 多元素命名构型 | 形 | 印章／徽章，稀缺三维体系 |
| 元数据 Meta | 关于知识的状态 | — | 固定隔离区，中性低饱和 |
| 装饰 Decor | 无语义 | — | 视觉从属，**不得僭越语义**（不与语义族形状冲突） |
| 聚合 Aggregate | 数量事实 | 支持 | 计数徽记，禁吉凶关联（§4.3） |

用户不读字即可答出"这是状态还是关系"——N1 的达成标准。

### 3.2 状态梯度【已决】

**独立灰度能量条＋五行色角标**（否决同色相亮度调制：浅色系梯度不显、深色系无差异、不可扩展多梯度）：

- 底部细灰度能量条表达强度（纯中性），角落小角标示五行身份色，形色完全分离；
- 能量隐喻贴合"气之进退"本义且无红绿灯价值预判。**残留风险（F2）**：血条语义"满格=健康=好"仍可能把"旺"读成"好"。三层对抗：首次接触 tooltip"旺非吉，衰非凶，只是气之进退"；旺衰词条首屏必放"忌神旺"反例；验收题库加"忌神旺是好是坏"测项；
- **十二长生**：同一灰度条 12 段分层映射（长生→帝旺递增、衰→墓绝递减），不建子系统；L1 只见五级，L3 解锁 12 级；词条标注"五级入门、十二级进阶"；
- **尺寸降级映射（F3）**：足尺寸 5／12 级 → 中尺寸 3 级（旺／平／衰）→ 极小尺寸仅高亮当令。降级映射进降级共享服务，分档依据强光／OLED 实测（§10 Phase A）。

### 3.3 五行色体系【候选值，真机出样后锁定】

| 五行 | 浅色模式 | 深色模式 | 备注 |
|---|---|---|---|
| 金 | 暖米白 #F5F5F0 | 金属浅灰 #D0D0D8 | 避免纯白刺眼／隐形 |
| 水 | 深靛蓝 #1A2030 | 暗青黑 #0D1018 | 替代纯黑，保留幽深本义 |
| 木 | 中度饱和青绿（双模式固定） | 同左 | |
| 火 | 降饱和赤红 | 标准赤红 | 浅模式防刺眼 |
| 土 | 标准黄褐 | 提亮黄褐 | 深模式防暗沉 |

铁律：颜色永不单独承载语义（形状／文字冗余编码）；locale 维度下色值可按文化语义微调（N6）。

### 3.4 关系线（RelationMark 专属语法）

- 箭头方向定作用指向（生→、克⇥、合⇌ 类，具体符号待典籍考据定稿，继承六爻／八字／奇门通用生克符号范式）；
- 线条虚实定强弱；线色为双方五行身份色（身份冗余编码，不承载价值）；
- **密度管控最严的物种**：默认按需显示（点选元素后在详情卡／盘面展开其关系），全量显示仅限高段位或教学场景。

### 3.5 格局印章与稀缺表达【P0-5 修订，对齐 v1.2 冻结项】

原"三维稀缺视觉体系"（纹理／边框／高光逐级）**阶段零完全移除**：即使声明"不代表吉凶"，逐级纹理高光仍会被理解为更厉害、更值得分享或类似抽卡稀有度，v1.2 已冻结稀缺格局的高光、召回和付费刺激。

阶段零替代方案：若需展示"少见"，只用**中性文本统计**，且必须同时显示材料范围、分母与 Registry 版本（如"在本库已编译的 N 部奇门文献中出现 M 次"）——不得把"当前数据库中少见"冒充"现实中罕见"。

三维稀缺视觉作为未来候选保留于 D-019 的 reserved capability（官方保留、用户样式不得复制），解冻须走 v1.2 冻结项流程。

### 3.6 三层递进披露与内联形态

```text
Glance  0.2s  形＋色（前注意层）——潜意识主战场
Read    1s    文字（识别层）
Tap     主动  元素详情卡→溯源词条（定义、原文、页码、流派差异）
```

每个标记绑定 Concept ID——**标记即最小的 Entry 入口**。正文流用内联变体（着色文字＋轻下划线），与块状件是同一 token 的两种密度，不是两套系统。

### 4.2 物种语义契约 Schema v2【已被拆分取代】

### 4.3 Counter 规则（后门全封）

- 禁止吉凶净值、比例、**及任何形式的吉凶数量对比**（"吉 0 凶 4"的视觉数量差同样传递"凶多吉少"的潜意识判决）；
- 只允许与吉凶无关的计数：格局总数、神煞总数、生克次数、重复出现次数（象牌 ×N 标识即此物种）。

### 4.4 ShenSha 强约束

神煞是流派分歧最大、伪知识点最多、最易制造吉凶焦虑的物种：L1 完全屏蔽；高阶层强制标注争议点；禁用一切绝对化吉凶描述；密度服务第一客户。此物种失守，产品单点退化为神煞恐吓套路。

### 4.5 色彩提级共享服务约束

提级依据优先级：**教学重点 ＞ 知识点稀缺度 ＞ 用户观感**；禁止以吉凶强度提级——否则禁区二从共享服务层被系统性违反，而每个物种单独看都合规。

## 5. 成长与密度体系

### 5.1 L 层级：作用域为 per-technique【v0.4 修正】

- L 层级按技法独立（八字 L3 ≠ 奇门 L3），否则跨技法用户被错误放开或屏蔽；
- L1（零基础）：**强制屏蔽全部神煞与冷门格局**，仅展示旺衰＋基础生克；状态梯度仅五级；
- L2：显现关系（**按需展开**，与 §3.4 一致）、角色、常见格局；全量关系线仅 L3＋教学场景可选开启；
- L3：十二长生 12 级、神煞（带争议标注）、技法特有参考表；
- 升级："系统提议＋用户确认"（熟悉度信号：图鉴进度／三秒小测），确认弹窗即成长庆祝时刻；
- 降级：长期未活跃静默降密度，**禁止"你退步了"式提示**（防降级羞辱）；保留手动切换。

### 5.2 与成长型 Widget 的同构

排盘页常驻参考 Widget（五行旺衰 → 天干十二长生 → 技法特有表）与 L 层级共用同一熟悉度信号与换代机制（见 From_Buyer_To_Owner §11.2）。

### 5.3 密度与性能预算

- 单屏同时可见语义族 ≤3（按 L 放开）；宁可少标，不可标满；
- 单屏 marks 渲染上限（具体值 Phase A 定），超限由密度服务裁剪，裁剪优先级复用 §4.5；
- ambient 动效（微光类）同屏上限，防圣诞树效应；动效纳入密度服务管辖；
- 低端机静态降级档；动效尊重系统"减少动态效果"。

## 6. 治理体系

### 6.1 视觉语法版本治理【v0.4 新增，与知识修订治理对等】

一致性习得意味着**视觉语法是对用户的长期承诺，改版＝用户已习得资产清零**。类 API 弃用策略：

- token 变更分级：非破坏性微调（色值微调、尺寸）直接发布；**破坏性变更**（形状语法、族归属改变）须双轨过渡期＋应用内公告；
- registry 版本与发布包（ReleaseBundle）版本联动，可回滚；
- 破坏性变更的决策门槛等同知识层 Schema 变更。

### 6.2 Tag Registry：唯一数据源

- 所有物种渲染由 registry 驱动，禁止页面手写样式（一致性的工程保障）；
- 契约校验（§4.2）、locale 资源、a11y label、telemetry 事件、文盘联动协议均居于此；
- **任何标记文案（含 label、tooltip、条件半句）不得脱离溯源管线徒手写**——连"土旺于未月还是火土同旺"都要带流派字段。

### 6.3 合规降级

compliance_profile（v1.1 §16A）通过降级共享服务实现：大陆 profile 下 OmenIndicator 降为中性形态标记、吉凶文案降为典籍描述式；海外 profile 全量。无需新机制。

### 6.4 流派差异强制展示【P0-3 修订：两级展示】

存在流派分歧的知识点（土旺月令、神煞取舍、格局判定），禁止以单一流派口径统一渲染。对齐 v1.2 要求，采用两级：

- **首层（盘面／卡片可见层）**：若分歧会改变用户当前判断，必须中性地显示"存在关键分歧"标识，不得被默认流派静默折叠；
- **详情层（Tap 层）**：展示各流派主张、条件、证据与当前所选流派配置；
- 不改变当前判断的次要分歧，可以只在详情层呈现。

"是否改变当前判断"的判定属于 MarkContentBinding 的内容状态字段，由知识层供给，不由 UI 猜测。

## 8. 红线汇总（合并版）

1. 借眼不代断：Marks 永不进入裁决层；聚合裁决、氛围渲染、无条件裸奔三禁区（视觉＋听觉双通道）。
2. 断格不断事：吉凶只作为典籍属性交付，四条件（元素级、三件套、溯源、静态盘标注）缺一不可。
3. 形定类别、色定取值，不得互换；颜色永不单独承载语义。
4. 状态中性于吉凶：能量隐喻，永不红绿；任何视觉权重不随用户个人吉凶变化。
5. 知识与元知识物理隔离。
6. 每个标记可溯源、可达（经元素详情卡）；无 Concept ID 的语义标记不允许存在。
7. 一处一义，处处同形；registry 驱动渲染，禁手写样式。
8. 流派分歧强制展示，禁单一口径渲染。
9. L1 强制屏蔽神煞与冷门格局。
10. Counter 禁一切吉凶关联展示。
11. 色彩提级依据禁用吉凶强度。
12. **稀缺视觉语言永不与付费、抽取、概率机制绑定**（防抽卡稀有度联想与赌博感知）。
13. 任何**术数知识文案**（术语、类象、条件半句、吉凶属性、流派表述，含其 a11y label）不得脱离溯源管线徒手写；**产品功能文案**（如静态盘标注提示语、操作引导）不需典籍出处，但仍须过五问审计的裁决测试。（第三轮修订：原表述"任何标记文案"过度扩张——"此为盘面格局属性"这类提示语没有也不需要典籍出处。）
14. 视觉语法破坏性变更须走版本治理，不得静默改版。

## 12. 第三轮评审发现【自洽性 × 术理深水区 × 跨文档依赖】

已直接修复：§2.3 盘→正文联动与"marks 不可点"的矛盾（改为经详情卡中转）；§5.1 L2 关系全量与 §3.4 按需默认的矛盾（改为按需）；红线 13 过度扩张（区分知识文案与产品文案）。

### 12.1 术理深水区（三项，Phase A 考据必答）

**G1｜合化与动态变性冲击"身份色稳定"假设（高）。**
关系语法只设计了生克合冲的静态表达，但"合"有合而化与合而不化——乙庚合**化金**后元素五行改变。若化气、从化成立，五行身份色角标是否随之变色？这是状态族（身份）与关系族（作用）的耦合点，当前语法假设身份色是稳定属性，术理上不成立。方向建议：本相色保持＋"化"标记叠加（保留教学线索"它本是乙木"），而非直接改色——具体规则 Phase A 与 RelationMark 符号考据一并定稿，且有流派分歧（化与不化的判定），需流派字段。

**G2｜状态族缺"非序数状态修饰"子型（高）。**
状态族只设计了序数梯度（旺衰五级／十二长生），但空亡、入墓、逢冲被破等是**布尔型状态修饰**，不在任何梯度上，传统有固定符号（如空亡标"○"）。需在状态族下分两个子型：序数梯度（能量条）＋状态修饰（传统符号继承），否则空亡这类高频核心概念无处安放。

**G3｜变动态表达缺失（中）。**
六爻动爻→变爻产生"同一位置的变化前后两态"，奇门有伏吟反吟的盘级形态。依附轴能否表达"变化前→后"？需确认物种体系对"时序双态"的承载方案（叠加？并置？详情卡内展开？）。

### 12.2 跨文档依赖冲突（一项，需回改 v1.1）

**G4｜最小盘面字典的依赖倒挂（高）。**
契约要求每个语义标记绑 Concept ID，Phase B 上线时盘面基础元素（十天干、十二地支、九星、八门、八神等约 100–200 个概念）全部需要 ID。但 v1.1 把 RuntimeFeature 字典推迟到了阶段 2——依赖倒挂。解法：把"最小盘面概念字典"（仅稳定 ID＋名称＋基础类象，**不含规则 DSL**）从 RuntimeFeature 字典中拆出，提前到阶段 1 必需项。此项需回改 `METAPHYSICS_KNOWLEDGE_COMPILATION_WORKFLOW_v1.1.md` §8.0 与 §20。

### 12.3 组件与工程补缺（四项）

**G5｜图例（Legend）组件缺失（中）。** 交通标志有驾校。用户应可随时呼出图例面板（当前 L 层级可见的全部形状语法一览），这是图表类产品的标准件，也是被动习得失败时的主动兜底。归 Phase B。

**G6｜未知物种的向前兼容（中）。** Registry 演进快于 App 版本，老版本遇到新物种／新枚举的降级规则未定义。规则：未知物种不渲染＋静默上报，禁止猜测渲染。写入契约校验器规格。

**G7｜视觉回归测试缺位（中）。** 一致性是全部前提，却没有自动化保障。物种 × 深浅模式 × 尺寸档 × locale 的快照矩阵（组合爆炸，需抽样策略），进 Phase B CI。

**G8｜北极星的测量机制未排期（中）。** "7 日视觉语法习得率"依赖应用内小测投放（无字识别的线上化），当前无归属。排入 Phase B-5（与埋点同批）；小测本身复用"三秒小测"机制（§5.1 升级信号），一件事两用。

### 12.4 阈值与兜底诚实化（两项）

**G9｜阈值未校准标注。** Phase A 的 >50%、北极星的 >60% 均为未经基线校准的初始值，正式阈值以 Phase A 原型测试基线为准——写明，防拍脑袋数字变成 KPI。

**G10｜被动习得失败的 Plan B。** 若 H28 失败（前注意习得不足以支撑概念学习），兜底路径：图例组件（G5）＋三秒小测＋词条首屏强化，从"纯被动"转"轻主动"——不推翻视觉语法，只增加主动通道。预先声明，避免 H28 失败时整个系统被误判为失败。
