# NC-020a BDD：消费端书籍契约核对清单

## 场景

### B-01 清单骨架生成

给定 上游回执 `UPSTREAM_DATA_CONTRACT_REPLY.md` 和消费端处理 `CONSUMER_ALIGNMENT_RESPONSE.md`
当 主 Agent 运行核对清单生成
则 产出 `BOOK_CONTRACT_ACCEPTANCE.md` 包含：
  - 政策与发布门禁章节（P-01～P-04）
  - 机器 Schema 与文件映射章节（S-01～S-07）
  - D-06 选区与迁移章节（D-06-01～D-06-05）
  - 资产与交付章节（A-01～A-06）
  - 真实样例章节（E-01～E-04）
  - D-07/D-08 依赖登记章节

### B-02 状态标注规则

给定 清单中任意一行有编号和状态列
当 状态列为空
则 校验脚本报错「状态列为空」

给定 状态列为「已交付」「有回执但未冻结」「未交付」之一
则 校验脚本通过

给定 状态列包含「已冻结」但不含「未冻结」
则 校验脚本报错「不允许跳过冻结步骤」

### B-03 校验脚本退出码

给定 清单所有行状态合法
当 运行 `check_book_contract.py`
则 退出码为 0

给定 清单存在至少一行状态非法
当 运行 `check_book_contract.py`
则 退出码为 1 且输出所有错误行号

### B-04 D-07/D-08 依赖登记

给定 清单包含 D-07 和 D-08 行
则 状态标注为「未交付」
且 依赖说明明确「不阻断独立笔记」
