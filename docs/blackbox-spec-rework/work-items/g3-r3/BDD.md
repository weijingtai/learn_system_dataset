# G3 R3 BDD

## B1 精确规范句

Given 规格包含固定的 Package 导语、向后兼容声明和 KnowledgePack 取代声明，
When 任一关键句被改名、否定、删除、重复或追加冲突内容，
Then 门禁非零退出；只有规范化后与权威句完全相等且恰好出现一次才通过。

## B2 精确映射表

Given §16.2 有 15 个目录 key、§16.3.2 有 5 个字段，
When 任一行缺失、重复、右值错误、追加第二归属，
Then 门禁非零退出；未知行或额外数据行同样失败。

## B3 精确接口块

Given §1 与 §16.3.1 定义三个 Tag 接口，
When 接口名不是精确名称、接口块不是恰好三个、一个块没有且仅有一条供给声明，或出现额外 Package，
Then 门禁非零退出。

## B4 变异装置可信

Given 一个变异用例，
When 目标文本没有被精确替换一次，
Then 变异脚本自身失败并报告 `MUTATION_NOT_APPLIED`；不得继续运行门禁并误报通过。

## B5 正常与回归

Given 权威规格未修改，
When 运行正常门禁和完整变异套件，
Then 正常门禁 `FAIL 合计: 0`，全部变异被拒绝，其他 T 类检查无退化，格式检查通过。

## B6 DSL 与 G4 双位置一致

Given §1 接口清单与 §16.3.1 详细接口块都声明最小盘面概念字典的限制，
When 任一位置缺少“严格声明不含规则 DSL”或缺少带命名空间的 `TAG_SYSTEM_DESIGN.md §12.2` G4 引用，
Then `G3-T08-DSL` 或 `G3-T08-G4` 必须非零；两个位置都精确存在且唯一时才通过。
