# NC-016b 执行提示

## 任务概述

在两台真实设备上验证私人同步的完整链路，包括 LAN 直连、WebRTC 信令、中转上传、接收端解密与宿主装配。

## 设备信息

- **设备 A**：华为 WGR-W09（Android 12，设备 ID `JCP6R21628000116`）
- **设备 B**：模拟器（Android 14，设备 ID `emulator-5554`）

## 执行步骤

### 第一步：验证设备连接

```bash
# 检查设备连接状态
adb devices

# 获取设备详情
adb -s JCP6R21628000116 shell getprop ro.product.model
adb -s JCP6R21628000116 shell getprop ro.build.version.release
```

### 第二步：启动应用

```bash
# 启动 reading-notes 应用
adb -s JCP6R21628000116 shell am start -n com.xuan.reading_notes/.MainActivity
```

### 第三步：执行配对

1. 在设备 A 上进入设置 → 设备同步 → 配对新设备
2. 在设备 B 上执行相同操作
3. 确认两台设备显示的配对码一致
4. 确认配对成功

### 第四步：测试数据同步

1. 在设备 A 上创建测试笔记
2. 观察同步状态
3. 在设备 B 上检查笔记是否同步成功

### 第五步：验证中转上传

1. 关闭设备 A 的 Wi-Fi（模拟跨网络）
2. 在设备 A 上创建笔记
3. 观察中转上传状态
4. 恢复设备 A 的 Wi-Fi
5. 在设备 B 上检查笔记

## 注意事项

- 确保两台设备在同一局域网内（前几步）
- 确保中转服务器可用（后几步）
- 记录所有日志和截图作为证据
- 遇到问题立即停止并记录

## 预期结果

- 设备发现成功
- 配对验证通过
- 数据加密传输成功
- 中转上传成功
- 接收端解密成功
- UI 更新正确
