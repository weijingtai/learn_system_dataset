# T-12 BDD 验收场景

## B1 增加层级列且不打乱盘点行序

Given 架构工程分为 L0 内核、L1 账本、L2 调度与各加工 Module，
When 执行者查看 §19 差距表格，
Then 表格新增「层级」列，逐行标注其对应工程层级（如 Module、L1、L2 等），且原有的行排列顺序保持完全不变。

## B2 施工拓扑与非施工顺序说明

Given 盘点表格按加工 Module 顺序排列，但底层依赖必须基础设施先于业务模块施工，
When 执行者阅读 §19，
Then 规格明确展示依赖拓扑关系，并在表格下方明确注明：「本表行序为盘点顺序，非施工顺序；施工顺序见上方拓扑，三个基础设施是前置层。」
