# PRD：古籍 OCR 识别与人工校对工作台

> 版本：v0.1（草案）
> 日期：2026-08-04
> 状态：需求整理，待评审
> 所属：learn_system / ocr

---

## 1. 背景与问题

本项目处理的是中国古代术数古籍（如《新刻琴堂五星》《三辰通载》等明代刻本）的数字化。

这些古籍的特点：

- **竖排为主**：列从右到左，列内从上到下；部分页面为图画式布局（星盘图、命盘图），文字沿曲线/斜向排布，不是整齐横排。
- **字形复杂**：明代雕版俗楷、异体字、生僻字多，通用 OCR 引擎（Apple Vision、PaddleOCR 通用权重）识别准确率不足，尤其曲线排布文字几乎必然出错。
- **版式干扰**：栏线、印章、纸张底色会破坏文本检测（豆包分析结论：栏线被误判为笔画/切割文本行，印章遮挡 ROI）。

已实测结论（2026-08-04）：
- Apple Vision 对竖排低清古籍整页识别基本失败（0 结果），分块放大后仅恢复书名与零星文字。
- PaddleOCR（PP-OCRv6，lang=ch）对竖排正文识别质量高（置信度 0.9+），但对图画式曲线文字识别为乱码。
- 需要"识别 → 人工校对"的闭环，纯自动 OCR 无法满足准确率要求。

---

## 2. 目标

构建一套"云端识别 + 本地校对"的古籍 OCR 工作台，实现：

1. **全量识别**：用 Colab（云端 GPU/免费算力）对古籍扫描图做全部 OCR 识别工作。
2. **逐字框选**：识别结果以"一个字一个框"为粒度输出。
3. **数据留存**：每张底图保存以下三样：
   - 底图本身（原图）
   - 每个字框的位置坐标（bounding box）
   - 每个框识别出的字（文本）
4. **原图复原**：可在原图上把识别出的框和字完整复原/叠加显示。
5. **方向调正**：对斜向/旋转的字，可旋转调正为正直方向显示。
6. **本地校对**：识别结果回传到本地后，人工可做以下操作：
   - 框选漏识别（漏选/未识别）的字，并给这些未识别框/未识别字做标注。
   - 对倾斜字在本地旋转调正。
   - 改正识别错误的字。
   - 查询/拆解生僻字（本地完成，不依赖云端）。

## 4. 数据格式设计（草案）

### 4.1 识别结果格式

每页一张底图对应一个结果文件，建议 JSON：

```json
{
  "page": "page_001",
  "image": "page_001.png",
  "width": 1092,
  "height": 1564,
  "chars": [
    {
      "id": "p001c0001",
      "box": {"x": 531, "y": 140, "w": 36, "h": 151, "angle": -12.5},
      "char": "貴",
      "conf": 0.99,
      "source": "ocr",
      "status": "verified"
    }
  ]
}
```

字段说明：
- `box`：矩形框（像素坐标，x/y 为左上角，w/h 为宽高）
- `angle`：字的方向角（度），0 表示正直；斜向字由 Colab 或本地旋转检测得出
- `char`：识别出的字；未识别/漏识别时可为空字符串
- `conf`：OCR 置信度（0-1）
- `source`：`ocr`（自动识别）| `manual`（人工补标）
- `status`：`pending`（待校对）| `verified`（已确认）| `corrected`（已改正）| `unrecognized`（未识别）

## 5. 功能规格

### 5.1 Colab 云端识别（R1/R2/R3）

- 输入：古籍扫描图（PNG/JPG）
- 处理：
  1. 预处理（可选）：自适应二值化、去栏线、去噪（实测对 PaddleOCR 非必需，保留开关）
  2. 文本检测：PaddleOCR（PP-OCRv6）→ 得到检测框
  3. 逐字切分：对检测框内的文字做单字分割（PaddleOCR 的 `rec` 输出按行/列，需按字间距或投影法二次切分为单字）
  4. 方向估计：对每个字估计旋转角 `angle`
  5. 识别：单字送入识别模型，输出字 + 置信度
- 输出：底图 + JSON（框坐标 + 字 + 置信度）+ 复原预览图
- 约束：全部识别工作由 Colab 完成，本地不跑识别模型

### 5.2 本地校对工作台（R4-R9）

- 加载：底图 + JSON
- 复原：在底图上叠加绘制所有框与字（可开关显示）
- 手动框选：未识别区域手动画框 → 标注为 `unrecognized`，并可补录文字（`source=manual`）
- 旋转调正：选中斜向框 → 拖动/输入角度旋转 → 预览正直效果 → 保存 angle
- 改字：点击框 → 编辑文字 → status 变为 `corrected`
- 生僻字查询：选中字 → 本地词典查询（见 §6）
- 生僻字拆解：选中字 → 拆出部首/部件（见 §6）
- 导出：校对完成后导出更新后的 JSON
