# 《穷通宝鉴》整本试运行章程（预注册版）

> 2026-07-11 开跑前写死。本章程即试运行的"球门"，开始后只许收紧不许放宽。
> 双重目的：① 真实产出（八字第一部典籍的知识资产）；② 压测流水线（类型 C 文本、整本规模、成本数据）。

## 一、合格判据（全书试运行 PASS 的条件）

| # | 维度 | 判据 |
|---|---|---|
| G1 | 完整 | outline 覆盖全书无缺口；每个条目要么完成编译、要么在账本里有明确的未做原因 |
| G2 | 程序质量 | 每批次校验（check_segments --type C、validate、validate_assertion_task）最终全 PASS；单批返工 ≤2 轮 |
| G3 | 人工质量 | 每批抽查 10%（至少 5 条）三问通过率 ≥95%；单批错 ≥2 条即整批打回重做 |
| G4 | 忠实红线 | 抽查与复核中发现"编造引用/擅改原文/模型自带知识入主张"零容忍——发现 1 例该批作废＋前后批扩大抽查 |
| G5 | 审计 | 每批有归档＋run.yaml；ESC 全部闭环（结束时无 open 状态）；editorial_notes 覆盖全部编者标记 |
| G6 | 成本 | 成本模型回填完成：每批 token 数、你的介入分钟数、返工率——**数据存在即合格，数值不设门槛**（首跑就是来测数的） |
| G7 | 检索 | 全书入库后 locate/concept/assertion 各抽 10 条查询全通；八字与奇门内容互不污染 |

## 二、不合格／停线判据（出现即停，先修流程再继续）

| # | 信号 | 动作 |
|---|---|---|
| S1 | 同类错误连续 3 个批次重复 | 停线。这是模板/规则没修好，不是执行问题——修 INSTRUCTIONS 和 LESSONS 再开 |
| S2 | 编造引用或擅改原文 ≥1 例 | 该批作废；相邻批次抽查率提到 30%；查明是提示词问题还是模型问题 |
| S3 | 覆盖检查反复无法闭合 | 底本文件本身有乱序/缺漏——回到找底本一步，换底本，不硬切 |
| S4 | 单批人工介入 >30 分钟 或 ESC 积压 >10 条 | 过程性不合格：说明自动化没兜住，停下修工具，不许用你的时间硬填 |
| S5 | 连续两周无人工验收 | 暂停生产。**无验收的产出不得签发**——宁可停线不欠质量债 |

试运行合格 ≠ 可对外发布：产物仍是内部知识资产（底本无影像核对、rights 未做发布级确认），对外走 v1.2 启动门，与本章程无关。

## 三、《穷通宝鉴》特有注意事项（六条，开跑前必读）

1. **底本有两个形态**：白文本（原文条目）与徐乐吾《造化元钥》式评注本（原文＋大量按语＝类型 D 混排）。**建议白文先行**（纯类型 C，风险低），徐注作为第二轮 D 类验证再叠加——一次只验证一个新变量。徐乐吾 1949 年去世，作品已过版权期；但**现代出版社的点校/标点本有版式与校勘权益**，电子文本来源按 ed02 同等规矩登记（来源、文字未核声明）。
2. **条目内嵌命例**："如某造：甲子、乙丑……贵至……"这类举例命造**不是主张**，是案例（Case）候选——工位 5 必须区分"通则"与"举例"，命例一律进 skipped 或单独标记 `case_candidate`，绝不提成 assertion（案例有独立流水线，v1.1.1 §8.4）。这是本书对流水线最大的新考验。
3. **结构极规整但依赖路径**：十干 × 十二月 ≈ 120 个条目，每条目的隐含条件就是它的路径（"三春甲木/正月"）——切分时 `entry_title`＋`path` 字段必填，主张的 conditions 必须继承路径条件（正月甲木的论断不许丢"正月"限定）。
4. **八字术语表从零开始**：本书属八字（bazi），奇门术语表不通用。第一批跑完先做术语候选提取＋你签发 bazi 术语表 v0，再放量——顺序和烟波钓叟歌一样。
5. **调候用神句高度公式化**（"得丙癸透，富贵双全"类）：这是将来规则候选的富矿，但现在只按普通主张处理，support_type 老实标注，不要提前结构化。
6. **C 类工具还没实战过**：C 类切分模板、segments 的 entry_title/path 字段、check_segments --type C 检查，目前都是纸面——所以第一批只做 **3 个条目**（OPERATOR_MANUAL 第 5 步纪律），工具验证过再放量。
