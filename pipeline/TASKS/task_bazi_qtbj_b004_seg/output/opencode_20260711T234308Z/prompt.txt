# 语义切分任务说明 · 类型 C（条目/表格）专用

你的唯一任务：把输入的条目式古文按**条目**切成若干段，**一个字都不许改、不许删、不许加**。
本说明是 stage3 通用切分说明的类型 C 特化版；与 HANDBOOK 第 3.2 节冲突时，以 HANDBOOK 为准并停下报告。

## 输入

- `input/text.md`：本批次的条目正文（一个 outline 叶子节点，如「三春甲木」整节）。
- `input/path.txt`：本节的卷章路径（如「论甲木 / 三春甲木」），**填进每段的 path 字段**。
- `input/context_before.md`（若有）：上一批末尾约 200 字，仅供理解指代，**不进入输出**。

## 输出格式（YAML）

```yaml
segments:
  - seg_id: s01
    entry_title: 正月甲木          # 本条目的标目（原文里的粗体条目名）
    path: 论甲木 / 三春甲木 / 正月   # path.txt 路径 + 本条目月令，末级到月
    text: <逐字复制的原文条目全文>
    note: <一句话说明本条目讲什么>
    case_candidate: false          # 见下方「命例识别」，含举例命造时改 true
```

- `seg_id`：从 s01 起顺序编号，两位补零。
- `entry_title`：本条目标目原文（如「正月甲木」「正二月甲木」）。总论/无标目的段填��节标题。
- `path`：卷章路径 + 本条目月令限定，末级尽量到「月」。**这是下游主张 conditions 的来源，不许省略月令。**
- `text`：条目全文，**必须与输入逐字一致**（程序 SEG_001 强制检查）。
- `note`：本条目自身讲什么，一句话，段段不同（禁止整节复制同一句）。

## 类型 C 切分规则（HANDBOOK 3.2）

1. **一个条目 = 一段**：「标目 + 正文（+ 若有注）」整体不拆散。穷通宝鉴体例里，「正月甲木，……」到下一个粗体标目前，是一条。
2. 条目内部再长也不拆（除非超过 2500 字才在段落边界对半切，见 HANDBOOK 4.2）。
3. 节首无标目的总述段（如「春月之木，渐有生长之象……」），单独成段，entry_title 填节名。

## 命例识别（本类型最关键，章程第 2 条）

条目里常嵌入**举例命造**，如「若庚申、戊寅、甲寅、丙寅，一行金水运，发进士」「或甲午日庚午时，此人必贵」。
- 这类是**案例（Case）候选，不是通则主张**。凡段内出现举例命造，**`case_candidate: true`**。
- 你**不拆出命例、不改写**，只在段级打标；下游工位 5 见此标记就知道「本段含命例，通则与举例要分开，命例不得提成 assertion」。
- 判据：段内出现 ≥2 个「干支组合」（天干+地支，如甲午、庚申）且语境是「若/或/如某造……主某某」→ 打标。程序 SEG_009 会提醒你。

## 约束

1. 所有段 `text` 拼接（去空白）必须等于输入原文（SEG_001）。
2. entry_title / path 必填（SEG_008），否则整批 FAIL。
3. 无法判断条目边界时，输出 `status: blocked_missing_context` 并说明缺什么，禁止猜测。

## 自查清单（交付前逐条过）

1. 每个粗体标目都单独成条了吗？没有把两个月的论述并进一条吗？
2. path 的月令限定写全了吗（「正月」不能丢）？
3. 含命造举例的段都标 case_candidate 了吗？
4. text 拼起来一字不差吗？

### 三秋甲木
三秋甲木，木性枯藁，金土乘旺，先丁后庚，丁庚两全，将甲造为画戟，七月甲堪为戟，非丁火不能造庚，非庚不能造甲，丁庚两透，科甲定然。庚禄居申，杀印相生，运行金水，身伴明君。或庚透无丁，一富而已，主为人操心太重，不能坐享。或丁透庚藏，亦主青衿小富。或庚多无丁，残疾之人若为僧道，灾厄可免。

或四柱庚旺，支内水多，不作弃命从杀。见土多可作从才而看。

庚多无癸，而壬水多，戊己亦多，此则专用一点丁火，方可制金以养群土，此命大富。丁藏富小，不显。丁露定作富豪。得二丁，不坐死绝，必然富贵双全，即风水不及，亦可富中取贵，纳粟奏名。

或癸叠叠制伏丁火，虽满腹文章，终难显达。得运行火土，破癸，略可假就功名，岁运皆背，刀笔之徒。

支成水局，戊己透干，制去癸水，存其丁火又可云科甲，但此等命，主为人心奸巧诈，好讼争非，因贪致祸。奸险之徒，决非安份之人也。

七月甲木，丁火为尊，庚金次之，庚金不可少。火隔水不能镕金，故丁火镕金，必赖甲木引助，方成洪炉。若有癸水阻隔，便灭丁火，壬水无碍，且能合丁，但须见戊土，方可制水存火。

八月甲木，木囚金旺。丁火为先，次用丙火，庚金再次。

一丁一庚，科甲定显。癸水一透，科甲不全。

丙庚两透，富大贵小。丙丁全无，僧道之命。

丙透无癸，富贵双全。有癸制丙，寻常之人。

支成火局，可许假贵，戊己一透，可作富翁。

或支成金局，干露庚金，为木被金伤，必主残疾，得丙丁破金，亦主老来暗疾。

或支成木局，干透比劫，反取庚金为先，次用丁火。

九月甲木，木星凋零，独爱丁火，壬癸滋扶，丁壬癸透，戊己亦透，此命配得中和，可许一榜。庚金得所，科甲定然。

或见一二比肩，无庚金制之，平常人也。倘运不得用，贫无立锥。一命，甲辰、甲戌、甲辰、甲戌、身伴明君，富贵寿考，此为天元一气，又名一才一用。遇比用才，专取季土。或见庚丙，可许入泮，白手成家。用火者，木妻火子，子肖妻贤。

或四柱木多，用丙用丁，皆不足异，耑用庚金为妙。凡四季甲木，总不外乎庚金。譬如木为犁，能疏季土，非庚金为犁嘴，安能疏土虽用丙丁，癸庚决不可少也。九月却不取土妻庚子，当取水妻木子。

凡甲木，多见戊己，定作弃命从才而看。从才格，取火妻土子。

或见一派丙丁伤金，不过假道斯文，有壬癸破了丙丁，技艺之流。无壬癸破火，支又成火局，乃为枯朽之木，有庚亦何能为力，定作孤贫下贱之辈，男女一理。

或有假伤官，得地逢生，此正合甲乙秋生贵元武之说，用水制伤官者，以金为妻，水为子。

或丁戊俱多，总不见水，又为伤官生财格，亦可云富贵，此格取火为妻，土为子。

凡甲多庚透，大贵。庚藏，小贵。若柱中多庚，则又以丁为奇，富贵人也。如庚申年、丙戌月、甲申日、壬申时，此主功名显达，有文学。若无庚丙年月，又无火星出干，虽曰好学，终困名场。

九月甲木，耑用丁癸，见戊透必贵。如戊戌、壬戌、甲子、甲申，支成水局，干有壬水，正合贵元武之说。配得中和，一榜之命，家计丰足。但庚丁未透出干，不能馆选。

甲乙比肩，又逢比劫运，主兄弟劫财争讼，刑妻损子。甲乙生正二月，无制无洩，主长发师姑。
