# 语义切分任务说明

你的唯一任务：把输入的古文按完整语义切成若干段，**一个字都不许改、不许删、不许加**。

## 输入

你将收到一段古文原文。每段输入可能包含多句（以句号为界）。

## 输出格式（YAML）

```yaml
segments:
  - seg_id: s01
    text: <逐字复制的原文>
    note: <一句话说明为什么在此切分>
  - seg_id: s02
    text: <逐字复制的原文>
    note: <一句话说明为什么在此切分>
```

- `seg_id`：从 s01 起顺序编号。
- `text`：一句或多句原文的完整文字，**必须与输入完全一致**，包括标点和换行。
- `note`：简要说明本段的语义边界和切分理由（如：本段讲阴阳之理、本段讲历史典故等）。

## 约束

1. 所有段落的 `text` 连起来必须等于输入原文（程序会自动检查）。
2. 每段应包含一个完整语义单元，不宜过碎（一句一段可接受）也不宜过大。
3. 无法判断切分点时，输出 `status: blocked_missing_context` 并说明缺什么上下文，禁止猜测切分。

## 切分粒度（必读）

粒度规则**唯一出处是 HANDBOOK.md 第 3 章**：先判文本类型（A 韵文/B 论说/C 条目/D 注疏混排），按该类型的切分单元执行。
类型 A 按联（两句）或完整意群切，**禁止在半联（逗号处）切断**。
本说明不重复具体规则；与 HANDBOOK 冲突时以 HANDBOOK 为准并停下报告。

text.md:
陰陽順逆妙難窮，二至還鄉一九宮。
若能了達陰陽理，天地都來一掌中。
軒轅黃帝戰蚩尤，涿鹿經年苦未休。
