# 语义切分任务说明 · 类型 C（条目/表格）专用

你的唯一任务：把输入的条目式古文按**条目**切成若干段，**一个字都不许改、不许删、不许加**。
本说明是 stage3 通用切分说明的类型 C 特化版；与 HANDBOOK 第 3.2 节冲突时，以 HANDBOOK 为准并停下报告。

**开工前必读**：`pipeline/lessons/LESSONS.md` 的"通用"＋"工位 3 语义切分"＋"大部头/类型 C 条目书"三个小节（几十秒，避开前人踩过的坑）；本任务包 `input/` 里若有 `editorial_notes.yaml`，括号内容的文层归属以它为准。

## 输入

- `input/text.md`：本批次的条目正文（一个 outline 叶子节点，如「三春甲木」整节）。
- `input/path.txt`：本节的卷章路径（如「论甲木 / 三春甲木」），**填进每段的 path 字段**。
- `input/context_before.md`（若有）：上一批末尾约 200 字，仅供理解指代，**不进入输出**。

## 输出格式（YAML）

```yaml
segments:
  - seg_id: s01
    entry_title: 正月甲木          # 本条目的标目（原文里的粗体条目名）
    path: 论甲木 / 三春甲木 / 正月   # path.txt 路径 + 本条目月令，末级到月
    text: <逐字复制的原文条目全文>
    note: <一句话说明本条目讲什么>
    case_candidate: false          # 见下方「命例识别」，含举例命造时改 true
```

- `seg_id`：从 s01 起顺序编号，两位补零。
- `entry_title`：本条目标目原文（如「正月甲木」「正二月甲木」）。总论/无标目的段填��节标题。
- `path`：卷章路径 + 本条目月令限定，末级尽量到「月」。**这是下游主张 conditions 的来源，不许省略月令。**
- `text`：条目全文，**必须与输入逐字一致**（程序 SEG_001 强制检查）。
- `note`：本条目自身讲什么，一句话，段段不同（禁止整节复制同一句）。

## 类型 C 切分规则（HANDBOOK 3.2）

1. **一个条目 = 一段**：「标目 + 正文（+ 若有注）」整体不拆散。穷通宝鉴体例里，「正月甲木，……」到下一个粗体标目前，是一条。
2. 条目内部再长也不拆（除非超过 2500 字才在段落边界对半切，见 HANDBOOK 4.2）。
3. 节首无标目的总述段（如「春月之木，渐有生长之象……」），单独成段，entry_title 填节名。

## 命例识别（本类型最关键，章程第 2 条）

条目里常嵌入**举例命造**，如「若庚申、戊寅、甲寅、丙寅，一行金水运，发进士」「或甲午日庚午时，此人必贵」。
- 这类是**案例（Case）候选，不是通则主张**。凡段内出现举例命造，**`case_candidate: true`**。
- 你**不拆出命例、不改写**，只在段级打标；下游工位 5 见此标记就知道「本段含命例，通则与举例要分开，命例不得提成 assertion」。
- 判据：段内出现 ≥2 个「干支组合」（天干+地支，如甲午、庚申）且语境是「若/或/如某造……主某某」→ 打标。程序 SEG_009 会提醒你。

## 约束

1. 所有段 `text` 拼接（去空白）必须等于输入原文（SEG_001）。
2. entry_title / path 必填（SEG_008），否则整批 FAIL。
3. 无法判断条目边界时，输出 `status: blocked_missing_context` 并说明缺什么，禁止猜测。

## 编者标记（括号夹注）处理（LESSONS 通用第 11 条，违反即偏差）

网络电子本常自带编者标记：括号夹注（如「癸在年（月）干」）、校补字、方括号。规矩：
- **原文里的括号照原样逐字保留在 text 里，一个字不许删**（忠实优先）；
- 但凡段内出现 `（）()【】[]` 括号，**必须在 result.yaml 的 uncertainties 里记一条**，注明 seg_id 和括号内容，交由复核方/工位 5 定文层归属（是原文、编者补字、还是异文）；
- 校验器 SEG_007 会对含括号的段告警——**看到 SEG_007 不是忽略，是提醒你去 result 记这一条**。

## 收尾：必须回填 result.yaml（教训回流，不许留空）

任务做完后，`output/result.yaml` 的这两个字段**不许无脑填空数组**：
- `uncertainties`：本批任何拿不准的地方（括号夹注、疑似异文、标目边界存疑）都列进来，一条一项，带 seg_id；
- `lesson_candidates`：本批发现的、值得写进 LESSONS 供后人避坑的规律，一句一条（如「本节原文只有 X 月标目、无 Y 月，条目数由标目定」）。真的什么都没有才留空——但含括号、切分数与相邻批不同时，几乎不可能为空。

## 自查清单（交付前逐条过）

1. 每个粗体标目都单独成条了吗？没有把两个月的论述并进一条吗？
2. path 的月令限定写全了吗（「正月」不能丢）？
3. 含命造举例的段都标 case_candidate 了吗？
4. text 拼起来一字不差吗？
5. 段内有括号的，result.uncertainties 记了吗？lesson_candidates 按实回填了吗（不是无脑空数组）？

### 三冬己土
三冬己土，溼泥寒冻，非丙暖不生，取丙为尊，甲木参酌。戊土癸水不用。惟初冬壬旺，取戊制之。余皆用丙丁，但丁不能解冻除寒，不能大济。

或干透一丙，支藏一丙，加以甲透，科甲有准。即藏丙无制，亦主衣衿。

或多壬水，得戊透制之，此命安然，富中取贵。不见戊土，富屋贫人。

凡三冬己土，见壬水出干，为水浸湖田，此人孤苦。若见火不孤，见土不贫。

金以至阴为体，中含至阳之精，乃能坚刚，独异众物，若独阴而不坚，冰雪是也，遇火则消矣。故金无火炼，不能成器，金重火轻，执事繁难。金轻火重，煅炼消亡。金极火盛，为格最精。金火全、名曰铸印。犯丑字、即为损模。金火多名为乘轩，遇死衰、反为不利。

木火炼金，成名锐而退速。纯金遇水，逢富显以赢余。

金能生水，水旺则金沉；土能生金，金多则土贱。金无水干枯；水重、则沉沦无用。金无土则死绝；土重、则埋没不显。两金两火、最上。两金两木、才足。一金生三水，力弱难胜；一金得三木，顽钝自损。金成则火灭，故金未成器，欲得见火；金已成器，不欲见火。金到申酉巳丑，亦可谓之成也，运喜西北，不利东南。

生于春月，余寒未尽，贵乎火气为荣；性柔体弱，欲得厚土为助；水盛增寒，难施锋锐之势；木旺损力，有挫钝之危，金来比助，扶持最妙。比而无火，失类非良。

夏月之金，尤为柔弱，形质未备，尤嫌死绝。火多而却为不厌；水盛而滋润呈祥；见木而助鬼伤身；遇金而扶持精壮；土薄而最为有用；土厚而埋没无光。

秋月之金，当权得令，火来煅炼，遂成钟鼎之材。土多培养，反惹顽浊之气。见水则精神越秀；逢木则琢削施威；金助愈刚，刚过则决。气重愈旺，旺极则衰。

冬月之金，形寒性冷；木多则难施琢削之功；水盛未免沉潜之患。土能制水，金体不寒，火来助土，子母成功，喜比肩聚气相扶，欲官印温养为利。
