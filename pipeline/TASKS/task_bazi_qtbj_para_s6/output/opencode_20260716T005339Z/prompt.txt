# 白话释义任务说明（工位 6·八字专版）

你的唯一任务：把 input/segments.yaml 里每个段落的原文，逐句翻成现代白话，供 APP 标注"机器释义"展示。**这不是讲解，是翻译。**

开工前必读：`pipeline/lessons/LESSONS.md` 的"通用"＋"工位 6"小节；本任务包 input/ 里的 `glossary_v0.yaml`（术语参照，遇到已确认术语时保留原词、不要自造解释）。

## 铁律（违反即整条作废）

1. **原文说多少译多少**。逐句对应，不许顺手补背景知识。原文写"用丙"，就译"取丙火为用"，**不许**扩写成"这里的丙火指十神中的食伤，因为……"——原文没说的一个字都不加。
2. **拿不准的词照抄原词加引号**。遇到不确定含义的术语（如"寒木向阳""假从"），白话里直接保留原词并加引号，**不许**换成某个具体的现代解释去猜。宁可留原词，不可猜错。
3. **保留原文的不确定性**。"或云""亦可""恐"这类模糊语气必须译出对应的不确定表达（"或云"→"也有说法认为"，"亦可"→"也可以"）。**不许**把模糊语气译成肯定句。
4. **⚠ 红线·不许强化吉凶判断**。原文"凶"就译"凶"、"贵"就译"贵"，**不许**扩展成"非常凶险，务必小心""大富大贵，前途无量"。吉凶的强度必须与原文一比一，不许放大也不许缩小。
5. **否定不许反**。"莫/勿/非/不可/最忌/怕"的否定方向在白话里必须保留。
6. 命例段（`case_candidate: true`）照常翻译——工位6只做翻译，命例的排除是工位5的事，这里如实译出即可。
7. **⚠ 遇乱码不猜字**。若原文含无法显示的字符（私用区乱码、显示为 □ 或异常方块、字体残缺字），`original` 照原样保留、**绝不自行猜字填补**，该条 `status: needs_escalation`，vernacular 里该字用 □ 占位并注明"疑为某字待核对原书"。宁可存疑，不可猜错钉进库。

## 编号
每条释义绑定其原文段的 span_id（在 segments.yaml 里每段都有），一段一条释义，不拆不并。

## 输出格式（YAML）

```yaml
paraphrases:
  - span_id: ss_qtbj_ed01_p0001_s02
    original: 正月甲木，初春尚有余寒，得丙癸逢，富贵双全。
    vernacular: 正月的甲木，初春还有残余的寒气，若同时得到丙火和癸水，主富贵双全。
    kept_terms: [丙, 癸]          # 照抄保留、未作解释的原词
    status: machine_translated    # 固定填这个，禁止填更高状态
```

## 自查清单（交付前逐条过）
1. 每段都译了吗？（覆盖：每个 span_id 都要有一条 paraphrase）
2. 有没有加原文没说的背景知识？（遮住原文只看白话，有没有多出来的信息）
3. 吉凶强度和原文一致吗？没有放大吗？
4. "或云/亦可/恐"的不确定语气都保留了吗？
5. 否定方向对吗？
6. 拿不准的术语是照抄加引号，还是擅自换成了现代解释？
