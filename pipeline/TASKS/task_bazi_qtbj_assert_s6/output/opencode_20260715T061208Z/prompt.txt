# 主张提取任务说明（工位 5·八字专版，全流程风险最高、规则最严）

你的唯一任务：对 input/segments.yaml 里的每个段落，提取"原文主张了什么"，一条命题一条记录，每条绑定证据。

开工前必读：`pipeline/lessons/LESSONS.md` 的"通用"＋"工位 5"小节；本任务包 input/ 里的 `glossary_v0.yaml`（术语参照，命中就用其 concept_id）。

## 铁律（违反即整条作废）

1. **只提取原文说了的，且 proposition 必须贴原文措辞，禁止意译/重述/改写**。你自己的八字知识一个字都不许进 proposition。proposition 应是原文字句的**直接摘取或最小限度整理**（可去虚词、可把主语补全，如"丙癸不可离"→"三春乙木丙癸不可离"），但**不许换成你自己的话**。
   - ✅ 对（照录）：原文"过与不及皆为乖道" → proposition："过与不及皆为乖道"
   - ❌ 错（意译）：原文"贵在折衷归于中道" → proposition："命理贵在折衷归于中道"（擅加"命理"）；原文"行运亦如之" → "行运同样遵循损有余补不足的原则"（整句改写＝违规）
   - 判据：把 proposition 里每个词拿回原文找，找不到对应字面的词就是你加的，删掉。
2. **⚠ 命例必须与通则分离，不是整段丢弃（本工位头号风险，最易误解）**：`case_candidate: true` 只表示**本段内含有命造举例**，不代表整段都是命例。工位3的定义（stage3c 模板）是"段内命例与通则要分开，命例不得提成 assertion"——**不是叫你把整段扔掉**。正确做法：
   - 段内的**通则部分照常提取主张**（如"七月丙火仍用壬水""正月丙火取壬为尊"这类取用/调候总纲，即使同段后面跟了命造举例，通则也必须提）；
   - 段内的**命造举例部分**（"如某命…主大贵""若庚申戊寅甲寅丙寅…发进士"这种"某盘→某断验"）**不提为主张**；
   - 只有当**整段确实除了命造举例再无任何通则**时，才把整段放 `skipped_segments`、`reason: case_example`。
   - ⚠ 大量含"富贵/科甲/登第"等吉凶断语的段其实是**通则**（"壬庚两透，科甲定然"是"壬庚两透"这个配置的通则断语，不是某个人的命造），**不要因为有吉凶词就当命例丢**。真命例的标志是出现**具体四柱**（≥2 组干支相连，如"丁未癸卯戊寅乙卯"）或"如/若/或 某造…主…"的举例句式。把通则当命例丢，会静默丢失整本书的核心断法——这比把命例误提成主张更隐蔽、更严重。
3. **证据绑定**：每条主张的 evidence 必须引用段落对应的 span（映射：seg_id sNN → source_span_id 用 input/spans.yaml 里该段的 span_id，形如 ss_qtbj_ed01_p0001_s01）。
4. **限定词全部进 conditions**：月令（"正月""三冬"）、旺衰、"若/凡/惟/独/偏宜/最忌"一个都不许丢。八字的断语高度依赖月令与配置，丢了就错。
5. **否定方向不许反**："莫/勿/非/不可/最忌/怕"提出来的主张必须保留否定。
6. **拆分粒度：一个"条件→断验"对 = 一条**。
   - 独立的条件断语各成一条：如"有戊稍有富贵。无戊常人"是**两条**（两个不同条件各有断验）；"用丙，佐以壬"是**两条**。
   - **补充/修饰成分不独立成条**，并入其主句：如"甲乃庚之良友"是对"用庚甲"的补充说明，并入而非单列；"可称上格"是前句断验的一部分，不单列。
   - 判据：这句话脱离上下文能否独立成立为一条"什么条件→什么结果"？能→独立成条；只是补充解释→并入主句。
7. **引用的歌诀/"书云/经曰/古歌"内容不单独提为主张**：原文引证他书的韵文（如"故书云：乙木根荄种得深…"）是引证不是本书主张，不提；但引文前后本书自己的断语照提。
8. 纯叙事/铺陈句没有可提取的主张 → 放 skipped_segments，reason: narrative，不是错误。
9. 两种读法都通 → 该段 needs_escalation，出 ESC 草稿放 result.yaml，继续做其他段。

## 编号
只用 task.yaml 里 id_range 分配的号段，assertion 与 proposition 同号段各自编号。

## 输出格式（YAML）

```yaml
assertions:
  - assertion_id: as_bazi_000001
    proposition: 正月甲木取丙火为用神，以解余寒
    proposition_id: pr_bazi_000001
    relation: supports          # supports / qualifies / opposes
    evidence:
      - source_span_id: ss_qtbj_ed01_p0001_s02
        support_type: direct    # direct=原文明说 / interpreted=通行解读
    conditions:
      - 正月（寅月）
      - 用于余寒未除之时
    exceptions: []
    concept_ids: [co_bazi_000xxx]   # 命中 glossary 的术语填其 id，没有留空
    status: machine_extracted   # 固定填这个，禁止填更高状态
skipped_segments:
  - seg_id: s03
    reason: case_example        # 仅当整段除命造再无通则时才用；含通则的段不进这里
```

## 自查清单（交付前逐条过）
1. **case_candidate 的段，我提取了其中的通则、只排除了命造部分吗？**（头号检查——不是整段丢！凡是 case_candidate 段进了 skipped，必须确认它整段真的没有任何通则）
2. 遮住 proposition 只看证据原文——原文真的这么说了吗？
3. 月令/旺衰等限定词都进 conditions 了吗？
4. 否定方向对吗？
5. 一条里藏着两条吗？
6. 每段都有交代吗（要么出主张、要么进 skipped）？
