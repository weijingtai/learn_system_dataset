# 术语候选提取任务说明 · 八字（bazi）专用

你的唯一任务：从输入的切分段落里，找出所有**八字命理专用词**，登记为候选清单。
本说明是工位 4 的八字特化版（奇门的星/门/神那套不适用）。

开工前必读：`pipeline/lessons/LESSONS.md` 的"通用"＋"工位 4"小节。发现新经验写进 result.yaml 的 lesson_candidates。

## 放量阶段：先闭集匹配，只提新词（三步判层，提效率）

若 input/ 里有 `glossary_v0.yaml`（已签发术语表），按三步走，把机器能定的先定掉：
1. **L1 共享源数据**：天干地支五行（甲乙…子丑…木火土金水）属共享 canon，**已知闭集，直接标 `layer: L1`、不必登记为新候选**（它们已在 schemas/shared/canon 里）；
2. **L2/L3 已在 v0 表**：surface 命中 glossary_v0.yaml 里已有的词 → 标 `matched: <concept_id>`，不算新词；
3. **新词**：v0 表里没有的术语才登记为新候选（candidates），走原格式。
这样每批只需人判"新词"，已知术语机器匹配，省时省 token。

## 什么算八字术语（只认这五类）

1. **十神**：正官、七杀、正印、偏印、食神、伤官、正财、偏财、比肩、劫财、阳刃/羊刃；
2. **格局/命象**：伤官生财、木火通明、阳刃驾杀、寒木向阳、财多身弱、水泛木浮、从才、从杀、从化、食神制杀 等有专名的格局；
3. **调候/五行作用**：调候、用神、司令、司权、进气、退气、相济、制杀、斲凿、镕金 等描述五行生克制化作用的专词；
4. **天干地支**：甲乙丙丁戊己庚辛壬癸、子丑寅卯…（单字干支按标准闭集纳入）；
5. **旺衰/十二运**：长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养、生旺、死绝 等。

普通文言词（如"富贵双全""余寒犹存"）不是术语。命造举例里的干支组合（"甲午日庚午时"）不是术语，是案例，跳过。拿不准的照样登记，但 `sure` 填 false。

## ⚠ "名曰X" 不等于 X 是术语（工位4最难的判断）

古籍"名曰/名为/号曰 X"是"它叫做 X"的句式，**不代表 X 就是受控术语**。要分两种：
- **标准术语**（收）：跨书复用、其他命书也这么叫的格局名——如"去浊留清""木火通明""羊刃倒戈""杀印相生"。
- **临时描述**（不收）：作者对某个具体命局的文学性盘面比喻——如"湖水汪洋""天和地润""乱臣无主奔波"。这类换本书就不再出现，是修辞不是术语。
判据：问自己"别的八字书里会不会也用这个词当术语？"会→收；只是这里形容这一盘→不收。拿不准填 sure=false 交复核，**不要因为有'名曰'就无脑收**。

## 硬性规矩

- `surface` 必须与段落原文**逐字一致**（复制粘贴）；
- **`seg_ids` 必须用全局 span_id**（形如 `ss_qtbj_ed01_p0005_s01`），不是批内的 `s01`——input 里的 `spans.yaml` 给出本批每段的 span_id 对照，照抄；
- 你只登记"哪个词在哪些段出现"，**禁止解释词义**（那要证据，是工位 5 的事）；
- 同一个词出现多段 → 一条记录，seg_ids（span_id）列全；
- **禁止用你自己的八字知识补充段落里没出现的术语**；只认原文真出现的。

## 输出格式（YAML）

```yaml
candidates:
  - surface: 阳刃驾杀
    kind_guess: pattern        # ten_god / pattern / tiaohou / stem_branch / phase / other
    seg_ids: [ss_qtbj_ed01_p0005_s04]
    sure: true
  - surface: 用神
    kind_guess: tiaohou
    seg_ids: [ss_qtbj_ed01_p0005_s02, ss_qtbj_ed01_p0006_s01]
    sure: true
```

kind_guess 枚举：`ten_god`（十神）/ `pattern`（格局）/ `tiaohou`（调候作用）/ `stem_branch`（干支）/ `phase`（旺衰十二运）/ `other`。

## 容错

- new_concept_candidates（词表没有的新词）是正常输出不是错误；
- 一段里术语超过一半是你没把握的 → 可能类型判断有偏，blocked 并说明；
- 同形不同义按上下文选（"死"在"死绝"是旺衰、在"死无棺椁"是普通词）拿不准 → 写 uncertainties。
